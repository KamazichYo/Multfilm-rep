# Мультфильмы: плоские человечки в 3D-мире

Вертикальные мультики для Instagram Reels / Shorts в стиле «круглая голова, палочки-руки, тело-боб — в настоящем
3D-городе», с чёрным контуром, размытым фоном и плавной камерой. Всё рисуется **кодом** (без видео-нейросетей)
и рендерится кадр за кадром.

Первый эпизод: **«Капитан из Кёпеника»** (Берлин, 1906) — `shorts/kopenick/` и `src/videos/kopenick/`.

## Чем пользуется автор ролика (по субтитрам и его архиву)
| Шаг | Инструмент |
|---|---|
| Мозг всего процесса | **Claude Code** (агент в терминале), «помощники» = субагенты, каждый со своей копией файлов |
| Скачать 20 образцов | **yt-dlp** |
| Разбор стиля «числами, а не на глаз» | **ffmpeg** + свои Python-скрипты: листы по 60 кадров (2 с), сдвиг картинки между кадрами (движение камеры), поиск склеек, яркость/контраст/насыщенность |
| Расшифровка текста образцов | Whisper (распознавание речи) → формула сценария (`STYLE_BIBLE.md`) |
| 3D-мир | **three.js** (через React Three Fiber) — дома, брусчатка, деревья построены кодом |
| Персонажи | рисуются на **Canvas 2D** (бобы, палочки, 14+ лиц), ставятся в 3D как плоские «наклейки», освещённые светом сцены |
| Чёрный контур «как в комиксе» | свой шейдер: ищет края по глубине/нормалям и обводит |
| Размытие фона, свечение, цвет | свои пост-эффекты (lens blur, bloom, color grade) |
| Видео кадр за кадром | **Remotion** (рендер React-сцены в mp4) |
| Голос | **Kokoro TTS** (англ.) + faster-whisper для таймингов слов |
| Музыка и звуки | синтез в Python (numpy) + сведение с «приглушением» под голос |

Его скилл лежит здесь: `.claude/skills/cartoon-3d-short/` — Claude Code в этом репозитории подхватывает его сам.
Его пошаговые промпты: `docs/author_START_HERE.md`.

## Что сделано в этом репозитории
- Скилл автора адаптирован под облако без видеокарты (программный WebGL `swangle`, MSAA 2) и под русский язык:
  голос **Piper `ru_RU-dmitri-medium`** (бесплатно, локально), тайминги слов — faster-whisper.
- Свой мир: площадь с жёлто-синими домами (палитра как в образце), красная кирпичная ратуша с башней и часами,
  фонтан, деревья, лавка старьёвщика, стол казначея. Свои персонажи: Фойгт (штатский → капитан), солдаты в
  пикельхельмах, мэр, казначей, полиция, кайзер, горожане. Свои эффекты: «?», монеты, расписка, пустой мундир,
  табличка «паспортов нет», паровозик.
- Своя музыка (марш «умпа-умпа» → минорное пиццикато на загадке) и звуки — всё синтезировано.

## Структура
```
src/videos/kopenick/   код эпизода: story.ts (планы, камеры), cast.ts (кто где, эмоции), world.ts (мир),
                       props.ts (2D-эффекты), toon.ts (рисование персонажей), ink/lensblur/grade (пост-эффекты)
shorts/kopenick/       script.txt, SCRIPT.md (факты, план), voice/ (voice.wav, words.json), audio/ (музыка+микс)
scripts/               render.sh, render_parts.sh, sheet.mjs (контактные листы), stills.mjs, contact.py
site/                  страница для GitHub Pages с готовым роликом
```

## Как собрать
```bash
npm install
npm run studio                                    # Remotion Studio в браузере: сцена, камера, таймлайн
node scripts/sheet.mjs out/sheet 40 '{"post":{"msaa":2}}' && python3 scripts/contact.py out/sheet out/sheet.jpg 9
scripts/render_parts.sh out/kopenick/v1 a         # кадры 0-819   (~75 мин без GPU)
scripts/render_parts.sh out/kopenick/v1 b         # кадры 820-1639
scripts/render_parts.sh out/kopenick/v1 join
ffmpeg -i out/kopenick/v1_silent.mp4 -i shorts/kopenick/audio/mix.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k -shortest out/kopenick/v1.mp4
```
Голос и звук:
```bash
piper -m ru_RU-dmitri-medium.onnx -f shorts/kopenick/voice/raw.wav --length-scale 0.8 < shorts/kopenick/script.txt
python3 shorts/kopenick/audio/make_audio.py shorts/kopenick/voice/voice.wav shorts/kopenick/audio/mix.wav
```
На компьютере с видеокартой рендер в разы быстрее: уберите `--gl=swangle` и поставьте `msaa` 4.

## Новая сценка для шоу
1. Напишите Claude Code: «Используй скилл cartoon-3d-short, сделай сценку про …». Своя история, свои персонажи.
2. Скопируйте `src/videos/kopenick/` → `src/videos/<имя>/`, зарегистрируйте композицию в `src/Root.tsx`.
3. Перепишите `story.ts` (планы под тайминги `words.json`), `cast.ts` (кто где и с какими лицами), при
   необходимости — мир в `world.ts`. Всё остальное (контур, свет, размытие, цвет, персонажи) переиспользуется.
